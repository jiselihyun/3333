# 2027 빵빵데이 천안 — 웹 프레젠테이션 (이미지 오류 수정판)

## 사용 방법
- `index.html`을 더블클릭하여 바로 실행합니다. 별도 이미지 폴더가 필요 없습니다.
- 이 파일에는 원본 PPTX의 10개 슬라이드 이미지가 내장되어 있습니다.
- 이전/다음, 키보드 방향키, 스크롤, 모바일 스와이프, 전체 목차, 텍스트 내용 보기 지원.

## GitHub Pages
1. GitHub 저장소 루트에 `index.html` 업로드
2. Settings > Pages > Deploy from a branch > main / (root) 선택
3. 발급된 URL에서 확인

## 참고
- 2027 행사 일정 및 프로그램은 공식 확정 여부를 확인하고 게시하세요.
- 원본 PPT의 시각 요소를 이미지로 보존하므로 슬라이드 안의 텍스트 편집은 불가능합니다.
- 웹 브라우저의 이미지 표시를 위한 외부 서버, 라이브러리, 리소스가 필요 없습니다.
